# Contributing

This is an experimental hardware project. Clear test evidence is more valuable than polished certainty.

When adding a design or firmware change:

1. State the problem being addressed.
2. Identify the hardware and revision tested.
3. Record relevant measurements.
4. Include failure modes and disappointing results.
5. Keep editable source files with exported artifacts.
6. Never commit passwords, tokens, private keys, Wi-Fi credentials, or personal data.

Use concise commit messages, for example:

```text
Document LEGO elbow backlash test
Add single-joint stepper experiment
Revise shoulder bearing mount to rev B
```
