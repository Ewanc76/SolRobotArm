# Media

Use this folder for selected project photos, diagrams, and short demonstrations that explain a revision or test.

Prefer descriptive names:

```text
2026-09-lego-arm-left-side.jpg
2026-09-100g-wrench-lift.jpg
rev-a-single-joint-test-rig.png
```

Large raw video files should generally remain outside Git unless Git LFS is deliberately configured. Link to hosted video and keep representative still images here.
